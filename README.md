# Credit Card Analysis Dashboard


This project presents an interactive dashboard for credit card transactions and customer behavior analysis using *Power BI* and *SQL*. It offers valuable insights into revenue generation, customer segments, transaction trends, and other key financial metrics.

---

## Tools & Technologies

- *Power BI* – For data visualization and dashboard creation  
- *SQL* – For data extraction, transformation, and aggregation

---

## Dashboard 1: Credit Card Transaction Analysis

### Key KPIs:
- *Revenue:* 55M  
- *Total Interest:* 7.8M  
- *Total Transactions:* 656K  
- *Transaction Amount:* 45M

### Visuals and Insights:
- Revenue by *Card Category* (Blue, Silver, Gold, Platinum)  
- Quarterly analysis of *Revenue vs. Transaction Count*  
- Usage pattern analysis by:
  - *Expenditure Type*
  - *Customer Qualification*
  - *Customer Job*
  - *Card Cost*  
- Chip usage comparison: *Swipe, **Chip, and **Online*  
- Filters: Gender, Card Type, Risk Level
